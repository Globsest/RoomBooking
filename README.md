# Система бронирования помещений

Java 17. Тесты используют JUnit 5.11.4; библиотека включена в lib.

## Быстрый запуск

1. Откройте `START.cmd` двойным щелчком.
2. Добавьте помещение: `room-add "Переговорная 1" 09:00 18:00 8`.
3. Скопируйте выданный ID помещения. Он также доступен через `rooms`.
4. Создайте бронь, заменив `ID` настоящим идентификатором:
   `book ID 2026-11-01T10:00 2026-11-01T11:00 "Иван Петров"`.
5. Введите `bookings` для просмотра или `bookings ID` для конкретного помещения.
6. Для отмены: `cancel ID_БРОНИ "Иван Петров"`.
7. Завершите командой `exit`. Снова запустите программу: данные сохранятся.

`help` показывает команды. Названия и имена с пробелами заключайте в двойные кавычки. ID - UUID, копируется полностью, без квадратных скобок.

## Правила

- Для помещения задаются название, вместимость и ежедневное время работы.
- Названия помещений уникальны без учёта регистра. Вместимость - положительное целое число; бронируется помещение целиком.
- Точность бронирования - одна минута. Формат: `ГГГГ-ММ-ДДTЧЧ:ММ`.
- Начало включается, окончание не включается: 10:00–11:00 и 11:00–12:00 совместимы.
- Пересечения запрещены только для одного помещения.
- Обычный период должен целиком укладываться в часы работы одного дня.
- Расписание `00:00 24:00` позволяет непрерывные брони на несколько дней.
- Закрытие в `24:00` означает полночь следующего дня. Открытие в `24:00` недопустимо.
- Отдельные ночные смены, праздники и расписание по дням недели в эту версию не входят.
- Все пользователи используют единое местное время учреждения, без часовых поясов и переходов летнего времени.
- Прошедшие даты разрешены - это полезно для учёта и воспроизводимых проверок.
- Имя владельца проверяется при отмене с учётом регистра. Это система без паролей: знание имени позволяет отменить чужую бронь. Для публичного сервиса нужна аутентификация.


## Архитектура


- `Room.java`, `Booking.java` - данные помещения и брони.
- `BookingState.java` - состояние в рамках транзакции.
- `BookingService.java` - рабочее время, пересечения и отмена.
- `BookingRepository.java` - чтение, сериализация, блокировка и атомарная запись.
- `TransactionOperation.java` - интерфейс операции внутри транзакции.
- `InputValidation.java` - проверка названий, времени и дат.
- `ConsoleApplication.java` - консольный интерфейс, команды и сообщения об ошибках.
- `RoomBooking.java` - точка входа с методом `main`.


## Тесты

- `tests/BookingServiceTest.java` - помещения, интервалы, пересечения и отмена.
- `tests/BookingRepositoryTest.java` - повреждённые данные, перезапуск и конкуренция процессов.
- `tests/ConsoleApplicationTest.java` - разбор команд и кавычек.
